# 复习中心设计（极简版）

> V1.1 第二步。核心：**相关文件夹里的复习图片/文档按文件名顺序读出来展示**。不做索引、不做 SRS、不做卡片分类——那些留后续拓展。

## 1. 存储

承接 `docs/v1.1.0.md` §3 文件路径重构，复习资料直接放对应文件夹：

```
root/
└── 课程文件夹/
    ├── 01_标题.mp4
    ├── 01_标题/                     # 素材同名文件夹
    │   ├── 01_标题.srt
    │   ├── 01_标题.json             # 字幕
    │   ├── 01_muddy.jpg             # 复习图片（按文件名自然排序）
    │   ├── 02_notes.png
    │   └── ...
    ├── 02_标题.mp4
    ├── 02_标题/
    └── 课程文件夹/                   # 课程同名文件夹
        ├── 01_overview.jpg          # 课程级资料（课程总览等）
        └── ...
```

- **无索引文件**：直接扫文件夹，取图片/文档扩展名，**PDF 优先、再按文件名自然排序**（复用 `natural_key`）
- 排除字幕 `*.srt`/`*.json` 与素材 `*.mp4`
- 图片：`.jpg .jpeg .png .gif .webp .bmp .svg`；文档：`.pdf`（可后续增 `.txt .md`）

## 2. 复习范围（基于已读）

- 素材级：`materials.read_at` 非空的素材 → 其同名文件夹里的图片/文档
- 课程级：该课程下**至少一个素材已读** → 课程同名文件夹里的图片/文档

## 3. API 契约

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/review` | 复习范围的分组列表：`{groups[]: {kind: course\|material, courseId, courseName, materialId, title, files[]: {name, url, kind}}}` |
| GET | `/api/review/file/{courseId}/{materialId}/{filename}` | 伺服单个图片/文档（`materialId=0` 表示课程级）；文件名必须真实存在于对应文件夹，禁止含路径分隔符（防目录穿越） |

## 4. 前端展示（第三步实现）

- 复习中心页：三级下钻——课程列表（只显示课程卡与资料计数，不展示图片）→ 课程内复习项（课程资料 + 素材资料）→ 详情
- 详情页内图片直接 `<img>`、PDF 用 `<iframe>` 内嵌预览，PDF 优先、再按文件名顺序
- 点击文件卡弹窗放大预览：左右切换（按钮 + 方向键）、Esc/遮罩/关闭按钮退出
- 无翻牌、无自测、无进度状态
