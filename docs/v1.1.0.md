# EnLearn V1.1 · 迭代方向

> 评估 2026-09（V1.0 完成后二次评估）。结论调整：主方向从「评分落库」改为「复习中心」；评分落库撤销。

## 0. 一句话结论

复习中心 = 基于已读课程的两维度资料展示（**课程资料** + **素材资料**），资料以「本地文件 + json 索引」组织（类比字幕 srt/json 的存储方式），本地获取图片/文档。落地分三步：**① 文件路径重构（现在）→ ② 资料存储格式设计 → ③ 复习中心页面**。

## 1. 撤销：评分落库

原 v1.1.0 主方向「scores 表 + `/api/score` 落库 + 弹窗历史」整体撤销。

- 历史分数没有消费出口：单机自用，没人翻"上月比这月进步没"；存的是已付费调用的结果，但无人看 = 纯成本
- V1.0 的"评分不落库、即时反馈"定位维持不变，`/api/score` 零改动

## 2. 为什么立复习中心

- **已读状态已沉淀**：`materials.read_at` 是现成入口，不需要新采集
- **复习材料不该只有视频重看**：图片/文档（生词卡、句子卡、课程总览、笔记）更适合碎片复习，视频重看成本太高
- **覆盖原候选「生词标记/句子收藏」的出口**：攒了词/句子需要一个能回看的地方
- **与原文反对的 SRS 不冲突**：这里做的是"复习资料浏览出口"，不是"记忆调度算法"；不做到期队列/艾宾浩斯/复习打卡

## 3. 文件路径重构（V1.1 第一步，现在做）

### 3.1 现状 → 目标

```
现状（V1.0）                            目标（V1.1）
root/                                  root/
└── 课程文件夹/                         └── 课程文件夹/
    ├── 01_标题.mp4                        ├── 01_标题.mp4        # 素材（不变）
    ├── 01_标题.json   ← 字幕              ├── 01_标题/           # 素材同名文件夹
    ├── 01_标题.srt    ← 字幕(可选)        │   ├── 01_标题.srt    # 字幕挪入
    ├── 02_标题.mp4                        │   ├── 01_标题.json   # 字幕挪入
    └── ...                                │   └── ...            # 素材级资料(后续设计)
                                           ├── 02_标题.mp4
                                           ├── 02_标题/
                                           │   └── ...
                                           └── 课程文件夹/        # 课程同名文件夹
                                               └── ...            # 课程级资料(后续设计)
```

- 素材 mp4 仍是课程文件夹的**直接子级**，识别规则不变
- 每个素材多一个**同名文件夹**：字幕 srt/json 挪进去，将来素材级资料也放这里
- 课程文件夹下多一个**与课程同名的文件夹**：存课程级资料（课程总览等）
- 其他直接子级文件/文件夹继续忽略（现状即忽略非 mp4 与子文件夹）

### 3.2 影响面

| 位置 | 现状 | 目标 |
|---|---|---|
| `admin_courses_import` 读字幕 | `f.with_suffix(".json")`（平铺同名） | `f.parent / f.stem / f.stem + ".json"`（同名文件夹内） |
| `/api/materials/{id}/srt` | `.with_suffix(".srt")` | 同名文件夹 `stem/stem.srt` |
| `/api/day` 的 `has_srt` 判断 | `.with_suffix(".srt").is_file()` | 同名文件夹判断 |
| 素材枚举 | 直接子级 `*.mp4` | 不变；同名文件夹与课程同名文件夹自然跳过（非 mp4） |
| srt-to-json 脚本 / SKILL 流程 | 平铺写同名 `.json`，输入平铺 `.srt` | 输出/输入落到素材同名文件夹 |
| `smoke_test.py` | 平铺构造 `1.alpha.srt` 等 | 构造嵌套目录，新增：嵌套字幕读取、嵌套 srt 读取、课程同名文件夹跳过 |

### 3.3 迁移与幂等

- 幂等键 `rel_path` 仍是 **mp4 的路径**，不变 → 重导 id 稳定，排期/已读/打卡不受影响
- 字幕 json 已入库，挪位置只影响"重导时能否再读到"；srt 端点每次现读，挪位即 404，需一并迁移
- 自用素材量小（月度 ≈30），**手动把现有 json/srt 挪进同名文件夹（或重跑 srt-to-json 流程）后重导**即可；不保留平铺 fallback（避免双路径分支）

## 4. 资料存储（第二步，已设计，极简）

详见 `docs/review-design.md`。核心：相关文件夹里的复习图片/文档按文件名顺序读出来展示，**无索引、无 SRS、无卡片分类**。

- 素材同名文件夹 = 字幕 + 该素材复习图片/文档；课程同名文件夹 = 课程级资料（总览等）
- 复习范围：素材级 = `read_at` 非空；课程级 = 课程下至少一素材已读

## 5. 复习中心页面（第三步）

- 入口：顶栏 / 课程中心新增「复习中心」
- 三级下钻：课程列表（只列课程卡，不展示图片）→ 课程内复习项（课程资料 + 素材资料）→ 详情页；图片直接显示，PDF 内嵌预览，PDF 优先、再按文件名顺序；点击文件卡可弹窗放大、左右切换
- 无翻牌、无自测、无进度状态

## 6. 明确不做（当前）

- 评分落库（撤销）
- SRS / 艾宾浩斯到期队列、卡片自测（后续拓展，见 review-design.md §5）
- 复习打卡
- 低分句重练清单（依赖评分落库，一并撤销）
- 听写模式（暂缓）
