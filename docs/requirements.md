# EnLearn 需求文档

> 英语学习网站：每日视频 + 双语字幕学习 + 跟读发音评分 + 打卡。单机自用，无登录、无云端。

## 1. 背景与目标

用本地英语视频材料做每日精听学习：看视频、逐句对照双语字幕、查重点词，看完打卡养成习惯。

**目标**：
- 一天一个或多个视频，日历即学习入口，进度一眼可见；另有自由播放入口，可直接点播本地任意文件夹中的视频
- 字幕以自定义 JSON 维护（含重点词/音标/笔记），比通用字幕文件信息量更大
- 逐句跟读并获得音素级发音评分，量化跟读效果
- Windows 双击即用，零配置

**非目标（明确不做）**：多用户/权限、在线视频、移动端适配、字幕自动生成、复习/艾宾浩斯算法、评分历史/趋势统计（首版评分不落库）。

## 2. 用户与场景

- 用户：本人单人使用
- 环境：Windows PC，视频为本地 mp4 文件
- 典型流程：打开网站 → 日历点当天 → 看视频（可调倍速）→ 对照右侧学习面板逐句跟读，遇到不懂的句子点它重播 → 对句子录音跟读，即时查看发音评分（准确度/流利度/完整度 + 逐词音素对比）→ 点「已完成打卡」→ 回日历看到当天已勾
- 自由播放流程：顶栏「自由播放」→ 选本地视频文件夹 → 点任意视频 → 底部字幕与右侧台词面板与日历播放一致（不计打卡、不做跟读）

## 3. 功能需求

### FR1 日历与打卡
- 首页展示当月日历，可切换月份
- 有排期的日期显示首条素材标题（一天多条时可见数量），点击进入播放页，页内可切换当天多条素材
- 已打卡的日期有明显标记（勾）
- 当天无任务时播放页给出"当天没有学习任务"提示

### FR2 视频播放
- 播放本地视频（服务端流式输出，支持拖动进度条，即 HTTP Range）
- 使用浏览器原生播放器：播放/暂停、进度拖动、倍速调节
- 加载视频时同时加载同目录同名 `.srt` 与 `.json`：srt 解析后内嵌在视频底部随播放显示，提供几种预置字幕样式（含关闭）；json 按字幕契约解析，展示在右侧学习面板
- 除日历外，顶栏提供「自由播放」入口：选本地文件夹列出视频点播，同名 srt/json 加载规则一致，不计打卡、不做跟读评分

### FR3 学习面板
- 播放器旁展示当天字幕句子列表：英文 + 中文翻译
- 每句可携带重点词（单词、音标、笔记）和整句笔记

### FR4 双向时间轴绑定
- 视频播放中，面板自动高亮当前句并滚动到可视区
- 点击任意句子，视频 seek 到该句开始时间并播放

### FR5 手动打卡
- 播放页提供「已完成打卡」按钮，手动触发打卡
- 打卡按天幂等：重复点击不产生重复记录
- 不再依赖播放进度（看到哪算哪，是否算完成由用户确认）
- 首次打卡顺带把当天全部素材标记为已读（手动已读的保留原时间）

### FR6 后台管理
- 顶栏齿轮图标进入后台；分三块：通用设置、课程管理、打卡管理
- **通用设置·统一前缀**：设置一次素材库根目录（存 `data/library.json`），之后所有导入与播放都相对它解析；挪整个素材库只改这一处；未配置时导入与播放不可用
- **课程管理·导入**：课程 = 统一前缀下被导入的文件夹（如 wowEnglish 第一季 = 1 课程 33 素材）
  - 选前缀内的文件夹（绝对路径或相对前缀的子路径——必须在统一前缀之下）一次导入整门课程：只取直接子级 `*.mp4`（不递归，子文件夹忽略），按文件名自然排序（数字段按数值，`10` 排在 `4` 后）
  - 素材标题去掉开头的 `1.` / `01_` / `001-` 序号前缀；同目录同名 `.json` 自动作该素材字幕（UTF-8），无则置空
  - 坏字幕 JSON 跳过并在结果中给出原因，且不占素材位；不匹配的非 mp4 文件忽略
  - 同一文件重导覆盖标题与字幕（id 稳定、已读与排期不受影响）；库里已有但文件夹里消失的文件保留不删
- **课程管理·列表/详情/删除**：课程列表显示素材数、已读素材数、已排日期；详情列出素材（标题/相对路径/句数/已读/已排日期）；删课程级联删其素材与全部排期（并清理因此变空的天的打卡）；也可单删一条素材
- **素材已读**：每条素材可手动切换已读（记已读时间，幂等）；当天首次打卡自动把当天素材标已读（手动已读的保留原时间）
- **打卡管理·排课**：选课程 + 日期区间（可跨月），素材自然排序后按天均分（33 素材 / 30 天 → 前 3 天各 2）；素材数少于天数时前 n 天各 1、后面留空（不报错，之后可逐天补）；已有排期上叠加
- **打卡管理·逐天调整**：给某天补素材（返回新增数）；移除当天一条素材；清空某天全部排期；清空当月全部排期与打卡；某天被排空时连带清掉当天打卡；月度排期视图显示每天的素材与打卡状态
- 排期来源仅限课程素材：不能绕过导入直接手录一条

### FR7 句子跟读发音评分（已实现：云知声 unisound provider，经真实 API 验收）
- 学习面板每句提供"跟读评分"入口：录音 → 提交 → 即时返回评分
- 评分以该句英文 `en` 为参考文本，展示三个维度：准确度（accuracy）、流利度（fluency）、完整度（completeness）
- 逐词结果：词级准确度分数；未说出/严重读错的词计 0 分并标注
- 评分失败（音频为空/过短/对齐失败）给出明确提示，不阻塞其他功能
- 首版评分不落库：刷新即丢，仅当次会话内查看（历史统计列为非目标）

## 4. 非功能需求

| 项 | 要求 |
|---|---|
| 部署 | Windows 双击 `start.bat` 一键启动（首次自动建 venv 装依赖），浏览器自动打开 |
| 架构 | 单进程服务（API + 前端静态文件同端口），本机 127.0.0.1 访问 |
| 持久化 | SQLite 单文件（`data/enlearn.db`），无外部数据库 |
| 兼容 | 现代 Chrome/Edge 即可 |
| 数据校验 | 非法输入返回明确 422 错误信息（含跳过原因），不产生脏数据 |
| 评分性能 | 评分接口采用同步 `def`（线程池执行）避免阻塞事件循环；每次调用是云 API 请求，量级毫秒~秒级 |
| 评分依赖 | 评分能力由 `backend/echoic/` 对接壳统一入口 + 多 provider 提供（已上线：云知声 unisound + mock，协议见 docs/scoring-provider-design.md，选型见 docs/scoring-api-research.md）；前端录音直接产出 WAV（16k/16bit/单声道），云 API 均不收 webm |
| 评分成本 | 按次计费的云 API，当前用云知声（候选对比见 docs/scoring-api-research.md），单机自用量级月成本个位数 |
| 依赖 | 后端 web 层仅 fastapi + uvicorn；前端仅 vue + vue-router，不引重型 UI/播放器库 |

## 5. 验收标准

- 后端冒烟 `python backend/smoke_test.py` 全部通过（统一前缀读写、课程导入新增/覆盖/跳过/消失保留、排课均分/留空/跨月/叠加、逐天补与移除、素材已读切换、删素材/删课程级联、422、Range 206、打卡幂等、SPA 托管、srt 端点、评分链路、scoring 配置读写）
- 前端 `npm run build` 零错误，`npm run test` 全部通过（日历渲染、句子高亮、点击 seek、跟读评分结果、录音 WAV 封装、课程导入、SRT 解析、多素材切换、字幕样式、本地播放）
- 手工验收：设好统一前缀 → 课程管理导入课程 → 打卡管理排课 → 日历可见 → 播放并拖动进度条，底部字幕与面板高亮跟随 → 切换字幕样式 → 点句子跳转 → 点「已完成打卡」回日历看到打卡标记（当天素材变已读）；顶栏自由播放选文件夹点播，字幕/台词面板同样生效
- 评分验收：对某句录音跟读 → 数秒内返回三维分数与逐词结果（已用云知声真实 API 走通完整链路）；断网/空录音场景提示错误而非卡死
