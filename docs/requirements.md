# EnLearn 需求文档

> 英语学习网站：每日视频 + 双语字幕学习 + 跟读发音评分 + 打卡。单机自用，无登录、无云端。

## 1. 背景与目标

用本地英语视频材料做每日精听学习：看视频、逐句对照双语字幕、查重点词，看完打卡养成习惯。

**目标**：
- 一天一个视频，日历即学习入口，进度一眼可见
- 字幕以自定义 JSON 维护（含重点词/音标/笔记），比通用字幕文件信息量更大
- 逐句跟读并获得音素级发音评分，量化跟读效果
- Windows 双击即用，零配置

**非目标（明确不做）**：多用户/权限、在线视频、移动端适配、字幕自动生成、复习/艾宾浩斯算法、评分历史/趋势统计（首版评分不落库）。

## 2. 用户与场景

- 用户：本人单人使用
- 环境：Windows PC，视频为本地 mp4 文件
- 典型流程：打开网站 → 日历点当天 → 看视频（可调倍速）→ 对照右侧学习面板逐句跟读，遇到不懂的句子点它重播 → 对句子录音跟读，即时查看发音评分（准确度/流利度/完整度 + 逐词音素对比）→ 看完自动打卡 → 回日历看到当天已勾

## 3. 功能需求

### FR1 日历与打卡
- 首页展示当月日历，可切换月份
- 配置了视频的日期显示视频标题，点击进入播放页
- 已打卡的日期有明显标记（勾）
- 当天无任务时播放页给出"当天没有学习任务"提示

### FR2 视频播放
- 播放本地视频（服务端流式输出，支持拖动进度条，即 HTTP Range）
- 使用浏览器原生播放器：播放/暂停、进度拖动、倍速调节

### FR3 学习面板
- 播放器旁展示当天字幕句子列表：英文 + 中文翻译
- 每句可携带重点词（单词、音标、笔记）和整句笔记

### FR4 双向时间轴绑定
- 视频播放中，面板自动高亮当前句并滚动到可视区
- 点击任意句子，视频 seek 到该句开始时间并播放

### FR5 自动打卡
- 视频自然播放结束，或观看进度 ≥ 90% 时，自动打卡
- 打卡幂等：重复触发不产生重复记录

### FR6 后台管理
- 日历页齿轮图标进入后台
- 增/删/改"每日视频"记录：日期（唯一）、标题、视频本地路径、字幕 JSON
- 视频路径可先验证文件是否存在（返回大小）
- 字幕 JSON 支持粘贴或导入 .json 文件，保存前服务端校验
- 删除视频时级联删除对应打卡记录

### FR7 句子跟读发音评分（规划中：评分库 echoic 已就位，接口与 UI 待实现）
- 学习面板每句提供"跟读评分"入口：录音 → 提交 → 即时返回评分
- 评分以该句英文 `en` 为参考文本，展示三个维度：准确度（accuracy）、流利度（fluency）、完整度（completeness）
- 逐词结果：词级准确度分数；未说出/严重读错的词计 0 分并标注
- 评分失败（音频为空/过短/对齐失败）给出明确提示，不阻塞其他功能
- 首版评分不落库：刷新即丢，仅当次会话内查看（历史统计列为非目标）

## 4. 非功能需求

| 项 | 要求 |
|---|---|
| 部署 | Windows 双击 `start.bat` 一键启动（首次自动建 venv 装依赖），浏览器自动打开 |
| 架构 | 单进程服务（API + 前端静态文件同端口），本机 127.0.0.1 访问 |
| 持久化 | SQLite 单文件（`data/enlearn.db`），无外部数据库 |
| 兼容 | 现代 Chrome/Edge 即可 |
| 数据校验 | 非法输入返回明确 422/409 错误信息，不产生脏数据 |
| 评分性能 | 评分接口采用同步 `def`（线程池执行）避免阻塞事件循环；模型实例按语言缓存，重复评分无重复加载 |
| 评分依赖 | 评分能力由 `backend/echoic/` 纯 Python 库提供（无 HTTP/无 DB）；系统依赖 ffmpeg 与 espeak-ng，缺失时英文评分静默退化（分数失真但不报错），需在文档标注 |
| 首次运行 | 评分模型（合计约 1 GB）首次调用时从 HuggingFace 下载并永久缓存，首次评分慢属正常，不算故障 |
| 依赖 | 后端 web 层仅 fastapi + uvicorn；前端仅 vue + vue-router，不引重型 UI/播放器库（echoic 的模型依赖见 backend/requirements.txt） |

## 5. 验收标准

- 后端冒烟 `python backend/smoke_test.py` 全部通过（CRUD、409/422、Range 206、打卡幂等、SPA 托管、级联删除）
- 前端 `npm run build` 零错误，`npm run test` 全部通过（日历渲染、句子高亮、点击 seek、后台表单校验）
- 手工验收：配置一天视频 → 日历可见 → 播放并拖动进度条面板高亮跟随 → 点句子跳转 → 看完 ≥90% 回日历看到打卡标记
- 评分验收：对某句录音跟读 → 数秒内返回三维分数与逐词结果 → 断网/空录音场景提示错误而非卡死 → 同一句重复评分结果稳定（模型确定性）
