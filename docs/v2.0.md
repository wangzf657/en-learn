# EnLearn V2.0 · 提炼式带学练习卡(播放页改版)

> 评估 2026-10。结论:**砍掉"今日台词"整块,教学 JSON 从「全台词逐句富化」转向「提炼式带学练习卡」**——播放页只保留浮层 srt 字幕轨 + 四板练习面板。本文是 V2.0 的契约与改版记录;机器可读 schema 权威仍是 `.agents/skills/srt-to-json/subtitle.schema.json`,生成流程权威是同目录 `SKILL.md`。

## 0. 一句话结论

看片归看片(浮层 srt,卡拉OK高亮,原样渲染),教学归教学(教学 JSON 只提炼一集最有价值的部分):**重点单词、重点短句、亲子场景对话、家长带学脚本**。家长的带学入口从"逐条台词里翻跟读"变成"一集一张练习卡 + 一屏带学脚本"。

## 1. 动机(产品决策)

- 跟读练习入口原来长在"今日台词"每一条上,想练要逐条翻找——练习应该是**精选过的**,不是全集
- 全台词逐句富化的 AI 成本高(207 集 srt→json 每句都要 zh/words/note),但消费端(台词面板)被浮层 srt 字幕轨大部分替代,投入产出倒挂
- 启蒙产品的核心是"家长会带":叽里呱啦/Lingumi 等都有每课家长指引——`guide` 板把"家长引导卡"落进数据契约
- 亲子共学需要"演出来"的对话素材,不是"读出来"的课文——`dialogues` 板从本集内容拓展日常生活场景

## 2. 新契约(四板)

```json
{
  "words":     [{ "w": "fix it", "zh": "修好它", "note": "修东西万能短语" }],
  "sentences": [{ "start": 11.2, "end": 12.5, "en": "The bike is broken!", "zh": "自行车坏了！" }],
  "dialogues": [{ "scene": "玩具坏了", "lines": [
      { "speaker": "parent", "en": "Oh no, it's broken!", "zh": "哦不，它坏了！" },
      { "speaker": "child",  "en": "Can you fix it?",     "zh": "你能修好它吗？" }
    ], "tip": "拿真玩具演一遍" }],
  "guide": { "goal": "…", "before": ["…"], "during": ["…"], "after": ["…"], "tips": ["…"] }
}
```

- **words** 4–8 条:`w` 是本集原声全文的表层连续词块(1–3 词),`zh` 必填,`note` ≤20 字
- **sentences** 3–6 句:**原声句的重点子集**——`en/start/end` 逐字逐秒来自原 SRT cue(跟读评分与跳转的地基,只能选不能造),`zh` 必填;语义从 V1.0 的"全量台词"显式改版
- **dialogues** 1–3 个:生成内容,parent/child 交替 4–8 行,启蒙可说出口的长度
- **guide**:`goal/before/after` 必填,`during/tips` 可选;before 是"给家长照着说"的话术,不是抽象建议
- 四板均可缺省但**至少一板非空**(空壳导入 422);无 version 字段
- **旧格式兼容**:V1.0 的 `{"sentences":[全量句]}` 仍是合法 JSON(sentences 是合法板),导入、透传、前端渲染都不炸——前端把它的 sentences 照常显示在"重点短句"区,guide 区走空态,直到重新生成

## 3. 页面改版

- **播放页右侧面板** = 紧凑分集 chips(`1 2 3…`,选中集全名在标题行,全集名进悬停 title)+ `PracticePanel.vue` 双 Tab:
  - **跟读练习 Tab**:重点单词 chips(点→跟读评分)/ 重点短句卡(点卡→跟读,⏱ 时间戳→seek)/ 亲子对话(点行→TTS 听单句,每段一个「跟读本段」按钮——整轮对话带进跟读;弹窗断句块按行显式传入,一行一整句,不按标点二次切分,`RepeatModal` 对显式 `segments` 优先、无显式时才按标点切分兜底)
  - **家长带学 Tab**:goal 高亮卡 + 播前/播中/播后/提示分组,纯阅读
- **RepeatModal 零改动**:它只读 `{en, zh, words[].w/note}`,对任意文本对象即插即用
- **LocalPlay(自由播放)同步改版**:同款 PracticePanel + RepeatModal;`SubtitlePanel.vue` 删除
- 浮层 srt 字幕轨、字幕样式、打卡、快捷键(空格/Enter/F11)全部不动;Enter 语义 = 收起/展开练习面板

## 4. 后端与数据(零迁移)

- `normalize_subtitle` 重写为四板浅校验(元素必填键+speaker 枚举+至少一板非空);深度契约(逐字对齐/词块子序列)仍在 `srt_tool check`,服务端有意不重复
- `subtitle_json` 是无 schema 的 TEXT,`/api/day`、`/api/admin/courses/{id}` 原样透传;`sentenceCount` 语义变为"重点短句数"(前端未展示)
- DB 无迁移(仍 v1);坏 JSON 与空壳四板都进导入 `skipped`,理由同为"字幕 JSON 无效"

## 5. 工具链(srt_tool.py)

- `draft` 不变:SRT → 全量句骨架(卡拉OK同文 cue 机械合并),**骨架 = 提炼候选池**
- `check` 重写:子集校验(en 逐字 ∈ 原 cue 文本且时间戳对齐 ±1e-6、words.w ∈ 全文 token 连续子序列、dialogues 结构+枚举、guide 必填键、数量软上限 WARN);旧格式全量文件给出"疑似旧格式,需重新提炼"WARN
- `dedup` 移除(对提炼式无意义);`selftest` 全量重写
- 落盘位置不变:素材同名文件夹内同名 `NN_标题/NN_标题.json`

## 6. 存量迁移(207 集 V1.0 → V2.0)

批量再生成走 `BATCH_BRIEF.md`:输入=旧 json(其 zh/words/note 可复用)+ srt;**批量前把旧 json 备份到课程文件夹下 `_v1_backup/`**(导入与复习中心都不扫它);逐文件写完立即 `check`;全批绿后 Admin 重导对应课程(幂等,id/排期/打卡不受影响)。备份保留至确认无回退需求。

## 7. 明确不做(本期)

- SRS/艾宾浩斯到期队列、卡片自测(维持 V1.1 决策;guide.after 的"播后提问"由家长口述执行)
- 评分落库(维持撤销决策)
- guide 单独路由/入口(就放在练习面板第二个 Tab)
- 旧 json 自动迁移脚本(一次性批量,走 BATCH_BRIEF 的人工/agent 流程即可)
